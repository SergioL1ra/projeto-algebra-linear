# Dados locais

Os arquivos do pacote do avaliador são dados de desenvolvimento e não devem
ser misturados ao código-fonte. Mantenha o pacote dos monitores fora deste
repositório ou em uma pasta local ignorada pelo Git.

O lote público contém matrizes `observada`, `mascara` e seus gabaritos. Use-o
para medir NRMSE e tempo, mas não presuma que os resultados públicos
representam o lote privado da avaliação final.
